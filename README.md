## 🚀 Projects

- 🔐 **SmartGate: Edge Security & Access Control** *(thesis, in design, build planned for 2028)*
  Face and license-plate recognition, time-window access rules, an IF-THEN automation engine, and Telegram alerts with image/video evidence. Vision runs locally on a Raspberry Pi 4B. STM32 I/O nodes drive barriers, locks, and sensors over RS-485 Modbus RTU.
  `Python` `OpenCV` `ONNX Runtime` `FastAPI` `STM32` `Modbus RTU`

- 🚁 **Drone Prototypes** *(Electrical-Electronics Dept. group project)*
  Designed, assembled, and programmed remote-controlled drone models, and tested several prototypes beyond the coursework.

- 🧊 **Robot Solving Cube** *(international collaboration, March 2025)*
  Joined a team of electrical-electronics students from EPHEC University, Belgium, to work on a cube-solving robot.
